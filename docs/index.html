🚀 30 秒快速开始

mpv 0.41+ · 一个 git clone 就绪。

# 依赖自检（自动报告缺失项）
git clone https://github.com/emoeem/mpv.git ~/.config/mpv
python3 ~/.config/mpv/deploy.py --check

# UI 字体按 UI-FONTS.md 放入 fonts/MFGA/（授权未定，需自备）
# 然后播放任意视频，右键打开菜单

⌨️ 常用快捷键

  • 右键菜单鼠标右键
  • 弹幕开关 / 菜单CTRL+D / CTRL+SHIFT+D
  • ASSRT 在线字幕CTRL+F
  • 内容类型切换（动画/真人/自动）CTRL+ALT+C
  • 可视化均衡器E
  • 画质配置组切换ALT+1~8
