30 秒快速开始

mpv 0.41+ · 一个 git clone 就绪，部署自检会自动报告缺失项。

# 克隆到 mpv 配置目录
git clone https://github.com/emoeem/mpv.git ~/.config/mpv

# 依赖自检（自动报告缺失项，四态报告）
python3 ~/.config/mpv/deploy.py --check

# UI 字体按 UI-FONTS.md 放入 fonts/MFGA/（授权未定，需自备）
# 然后播放任意视频，右键打开菜单

常用快捷键

完整的 900+ 键位见仓库 README 快捷键全表；以下是最常被按到的那几个。

  • 右键菜单鼠标右键
  • 统计信息（临时 / 常驻）i / I
  • 观影时长统计页7
  • 弹幕开关 / 综合菜单CTRL+d / CTRL+D
  • 弹幕屏蔽词管理CTRL+SHIFT+L
  • ASSRT 在线字幕CTRL+f
  • 内容类型切换（动画/真人/自动）CTRL+ALT+c
  • 可视化均衡器e
  • 画质配置组切换ALT+1~8
